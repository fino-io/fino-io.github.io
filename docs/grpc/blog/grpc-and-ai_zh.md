我们最近在 gRPConf 2024\ 上展示了大型语言模型 (LLM) 在转变 gRPC 开发方面的令人兴奋的潜力。如果您想了解 AI 如何简化您的 gRPC 工作流程，请继续阅读！我们想强调的是，您*今天*可以使用 [Gemini Code Assist](https://codeassist.google/) 访问这些功能。

在我们的 gRPConf 演示中，我们探讨了法学硕士（尤其是 Google 的 Gemini）如何通过三种关键方式简化您的 gRPC 工作流程。现在让我们以 Gemini Code Assist 为例，看看如何利用 LLM 的 gRPC 知识：

1. **Swagger 到 Protobuf：探索作为 gRPC 服务的 API：** 想知道作为高性能 gRPC 服务的现有 REST API 是什么样子？打开 OpenAPI YAML 文件，然后编写如下提示

*“将 OpenAPI 架构转换为 Protobuf”*

探索 gRPC 对您当前服务的潜力、加速采用并发现 API 架构的新可能性。

2. **Protobuf 到 JUnit 测试用例：增强您的测试工作流程：** 想要确保您的 gRPC 服务稳健可靠吗？您可以使用类似的提示

*“为在 petstore.proto 中实现 PetStoreService 的服务创建 JUnit 测试”*

从 Protobuf 定义自动生成全面的 JUnit 测试用例。体验如何使用多种语言（Java、Go、Python 等）快速创建测试，使您能够自信地专注于构建创新功能。

3. **自然语言到 Protobuf：释放您的服务理念：** 对新的 gRPC 服务有愿景吗？您可以使用以下提示直接用简单的英语描述您的服务理念

*“帮我创建一个宠物商店gRPC服务，它应该列出所有宠物，创建一个新宠物，并通过ID获取宠物信息。”*

生成 Protobuf 模式。了解如何快速构建新服务原型、促进团队之间的协作以及轻松将您的想法变为现实。

像 Gemini 这样的法学硕士对 gRPC 概念和代码结构有深入的了解，使您能够在开发工作流程中利用它们。我们很高兴继续探索法学硕士的潜力，以进一步简化工作流程、自动化任务，并帮助开发人员构建和维护高质量的 gRPC 服务。
