[Cloud Run][] 是 Google Cloud 提供的无服务端平台，可让您在完全托管的环境中运行无状态服务端容器。大多数 Cloud Run 应用程序使用 HTTP JSON REST 来服务请求，但自 2019 年 9 月起，应用程序也可以使用一元 gRPC 服务！

<!--more-->

从 [不再仅适用于 HTTP：gRPC 来到 Cloud Run][] 获取所有详细信息。
