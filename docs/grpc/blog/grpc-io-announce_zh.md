想要在关键 gRPC 公告上保持领先地位吗？我们为您服务！

隆重推出 [grpc-io-announce](https://groups.google.com/g/grpc-io-announce)，这是一个新的邮件列表，专门用于直接向您的收件箱发送重要更新。这个高信号通道可以消除噪音并专注于最重要的事情，包括：

- **安全漏洞和可靠性问题**：成为第一个知道的人
了解安全问题并及时获取有关修复和缓解措施的更新。
- **主要平台支持变更**：随时了解支持变更
针对不同的平台。
- **项目和治理新闻**：获取重大项目的最新动态
里程碑和治理决策。

注意：发布公告和功能发布公告将保留在现有的 [grpc-io 组](https://groups.google.com/g/grpc-io) 中。

不再需要搜索 grpc-io 组或担心丢失关键信息。订阅 **grpc-io-announce** 并放心，您不会错过重要信息。

**今天加入群组：[grpc-io-announce 群组](https://groups.google.com/g/grpc-io-announce)**

欲了解更多信息，请参阅[P6 grpc-io-announce](https://github.com/grpc/proposal/blob/master/P6-grpc-io-announce.md)。

我们致力于让您随时了解情况并确保流畅的 gRPC 体验。
