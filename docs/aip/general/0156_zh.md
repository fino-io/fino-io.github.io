# 单例资源

有时资源在每个给定父资源下始终且仅存在一个实例，配置对象是常见例子。

## 指导

API **可以**定义单例资源。父资源存在时，单例资源必须存在，并且每个父资源只能有一个：

```proto
message Config {
  option (google.api.resource) = {
    type: "api.googleapis.com/Config"
    pattern: "users/{user}/config"
  };
  string name = 1 [(google.api.field_behavior) = IDENTIFIER];
}
```

单例资源的资源名称模式通常不包含资源 ID 占位符，而是使用固定集合键（如 `config`）。不应提供 Create 或 Delete，因为创建/删除由父资源生命周期隐含；应提供 Get 和 Update。若需要初始化，可以让首次 Update 创建配置，但必须明确该语义。

单例资源应遵循普通资源的字段、权限、强一致性和声明式友好要求。父资源删除时，单例资源应一并消失；因此 Delete 父资源时即使存在单例子资源，也不能据此阻断删除。

## 设计缘由

### 支持标准 List

List 方法通常用于集合，但单例资源的集合最多只有一个元素。API 可以支持 List 以便通用客户端工作；如果不支持，AIP-132 允许将单例资源作为例外。

### 包含 `plural` 定义

资源描述中的 `plural` 可以提供单例资源的复数形式，帮助工具生成集合路径和文档；它不改变单例资源每个父资源仅有一个实例的语义。
