# 跨集合读取

有时用户需要跨多个集合获取资源，或在不知道资源所属集合时获取单个资源。

## 指导

API **可以**允许在标准 `List` 方法中使用 `-`（连字符/短横线）作为通配符：

```http
GET /v1/publishers/-/books?filter=...
```

- URI 模式仍**必须**使用 `*` 并允许调用方指定集合；模式不得把 `-` 写死。
- 服务必须明确跨集合查询的授权、排序、分页和结果一致性语义。
- 当资源名称本身已知时，Get 应继续使用完整资源名称，而不应要求调用方先列出所有集合。

### 唯一资源查找

如果用户只知道资源的唯一属性而不知道父集合，API 可以提供专用查找方法，但应优先考虑过滤后的跨集合 List。查找结果必须明确零个、一个和多个匹配项的行为，不能静默选择任意资源。
