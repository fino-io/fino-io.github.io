# 数量

许多服务需要表示离散数量，例如字节数、英里数或节点数。

## 指导

带有明确计量单位的数量**必须**以单位作为后缀；适当时**应**使用通用缩写，且缩写不应复数化，例如使用 `distance_km` 而非 `distance_kilometers`。

```proto
message Route {
  string origin = 1;
  string destination = 2;
  int32 distance_miles = 3;
}
```

表示项目数量时，字段**应**使用 `_count` 后缀，而不是 `num_` 前缀，例如 `node_count`。字段**不得**使用无符号整数类型，因为许多语言和系统对其支持不佳。

### 复合单位

复合单位可以按需使用下划线。未缩写单位**必须**分隔；缩写单位通常不应分隔，除非会产生歧义。复合单位**应**使用复数，除最后一个单位外各部分用单数；最后一个单位除非缩写，否则使用复数，例如 `energy_kwh`、`energy_kw_fortnights`。公制前缀不得与基本单位分开。

### 倒数单位

包含倒数单位时，非倒数单位之后应使用 `per` 加倒数复合单位，倒数复合单位**应**使用单数，例如 `speed_miles_per_hour`、`speed_meters_per_second`、`event_count_per_hour`、`price_per_kwh`。若已有通用的派生单位名称（如 hertz），应优先使用派生单位。

### 专用消息

需要将多个数量组合，或单位本身可能变化时，可以定义表示数量的消息，例如 [`google.protobuf.Duration`][duration] 和 [`google.type.Money`][money]。将此类消息作为字段时，如果直观可行，字段后缀**应**使用消息名称。

[duration]: https://github.com/protocolbuffers/protobuf/blob/master/src/google/protobuf/duration.proto
[money]: https://github.com/googleapis/googleapis/blob/master/google/type/money.proto
