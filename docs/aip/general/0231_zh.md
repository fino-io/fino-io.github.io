# 批量方法：Get

一些 API 需要允许用户在一致的时间点获取一组特定资源（例如使用读事务）。批量 Get 方法提供了这一能力。

## 指导

API **可以**使用以下模式支持 Batch Get：

```proto
rpc BatchGetBooks(BatchGetBooksRequest) returns (BatchGetBooksResponse) {
  option (google.api.http) = {
    get: "/v1/{parent=publishers/*}/books:batchGet"
  };
}
```

- RPC 名称**必须**以 `BatchGet` 开头，名称其余部分**应**是所获取资源的复数形式。
- 请求和响应消息**必须**与 RPC 名称匹配，分别使用 `Request` 和 `Response` 后缀。
- HTTP 动词**必须**是 `GET`。
- HTTP URI **必须**以 `:batchGet` 结尾。
- URI 路径**应**表示资源集合，并与简单 CRUD 操作使用的集合一致。如果操作跨越多个父资源，可以接受短横线（`-`）作为通配符。
- `google.api.http` 注解中**不得**有 `body` 键。
- 操作**必须**是原子的：要么所有资源失败，要么所有资源成功（不允许部分成功）。如果需要部分失败，**应**使用 List（[AIP-132][]）方法。
  - 如果操作覆盖多个位置，且至少一个位置不可用，操作**必须**失败。

### 请求消息

批量 Get 方法的请求**应**使用以下模式：

```proto
message BatchGetBooksRequest {
  // 所有要获取图书共享的父资源。
  // 格式：publishers/{publisher}
  // 如果设置此字段，则 names 中所有图书的父资源必须匹配该字段。
  string parent = 1 [
    (google.api.resource_reference) = {
      child_type: "library.googleapis.com/Book"
    }];

  // 要获取的图书名称。
  // 一次批量最多获取 1000 本图书。
  // 格式：publishers/{publisher}/books/{book}
  repeated string names = 2 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      type: "library.googleapis.com/Book"
    }];
}
```

- 除非要获取的资源是顶层资源，否则**应**包含 `parent` 字段，以便将其放入 URI 并执行一次权限检查。如果调用方设置了该字段，而任一要获取资源名称中的父集合不匹配，请求**必须**失败。
  - 如果每个请求只允许一个父资源，该字段**应**为必需。
  - 该字段**应**标识其引用的[资源类型][aip-122-parent]。
  - 字段注释**应**记录资源模式。
- 请求消息**必须**包含一个重复字段，接受指定要获取资源的资源名称；该字段**应**命名为 `names`。
  - 如果没有提供资源名称，API **应**返回 `INVALID_ARGUMENT`。
  - 该字段**应**为必需。
  - 该字段**应**标识其引用的[资源类型][aip-122-names]。
  - 字段注释**应**记录资源模式。
- 除 `name` 外，其他字段**可以**从[标准 Get 请求][request-message]“提升”到批量请求中。这样无法让这些字段针对不同资源接受不同值；如有需要，应使用[嵌套请求消息形式](#嵌套请求对象)。
- Batch Get **不应**支持分页，因为跨 API 调用实现或强制事务性会极其困难，而且请求已经定义了响应的准确范围。
- 请求消息**不得**包含其他必需字段，且除本 AIP 或其他 AIP 描述的字段外，**不应**包含其他可选字段。
- `names` 字段上方的注释**应**记录允许的最大请求数量。

### 响应消息

批量 Get 方法的响应**应**使用以下模式：

```proto
message BatchGetBooksResponse {
  // 请求的图书。
  repeated Book books = 1;
}
```

- 响应消息**必须**包含一个与所获取资源对应的重复字段。
- 响应中图书的顺序**必须**与请求中名称的顺序相同。

### 嵌套请求对象

如果[标准 Get 请求消息][request-message]除资源名称外还包含一个字段，且该字段对请求中的不同资源需要使用不同值，则批量消息**可以**改为包含一个重复的[标准 Get 请求消息][request-message]字段。除非使用场景确实需要，否则通常不建议这样做。

采用这种方式时，批量 Get 方法的请求**应**使用以下模式：

```proto
message BatchGetBooksRequest {
  // 所有要获取图书共享的父资源。
  // 格式：publishers/{publisher}
  // 如果设置此字段，GetBookRequest 消息中的 parent 字段必须为空
  // 或与该字段匹配。
  string parent = 1 [
    (google.api.resource_reference) = {
      child_type: "library.googleapis.com/Book"
    }];

  // 指定要获取图书的请求。
  // 一次批量最多获取 1000 本图书。
  repeated GetBookRequest requests = 2
    [(google.api.field_behavior) = REQUIRED];
}
```

- **应**包含 `parent` 字段。如果调用方设置了该字段，而任一要获取资源名称中的父集合不匹配，请求**必须**失败。
  - 如果每个请求只允许一个父资源，该字段**应**为必需。
  - 该字段**应**标识其引用的[资源类型][aip-122-parent]。
  - 字段注释**应**记录资源模式。
- 请求消息**必须**包含一个重复字段，接受按[标准 Get 方法][request-message]定义的指定要获取资源的请求消息；该字段**应**命名为 `requests`。
  - 该字段**应**为必需。
- 其他字段**可以**从[标准 Get 请求][request-message]“提升”，即字段可以在批量层级或子请求层级设置。与 `parent` 类似，如果同一字段在两个层级都设置，值**必须**匹配。
- Batch Get **不应**支持分页，因为跨 API 调用实现或强制事务性会极其困难，而且请求已经定义了响应的准确范围。
- 请求消息**不得**包含其他必需字段，且除本 AIP 或其他 AIP 描述的字段外，**不应**包含其他可选字段。
- `requests` 字段上方的注释**应**记录允许的最大请求数量。
