# 时间与时长

日历、时区和 JSON 等交换格式缺少原生时间概念，使时间表示容易出错。时间字段**应**使用通用组件，例如 [`google.protobuf.Timestamp`][timestamp]、[`google.type.Date`][date]；统一使用这些[通用组件][aip-213]有利于基础设施和工具提供一致体验。

## 指导

### 时间戳

表示与时区或日历无关的绝对时间点时，**应**使用 `google.protobuf.Timestamp`，字段名**应**以 `_time` 结尾；重复字段使用 `_times`。表示活动发生时间时使用 `{imperative}_time`，例如 `publish_time`，而不是过去时态的 `published_time`、`created_time` 或 `last_updated_time`。

### 时长

表示两个时间点之间的时长时，**应**使用 [`google.protobuf.Duration`][duration]。

```proto
message FlightRecord {
  google.protobuf.Timestamp takeoff_time = 1;
  google.protobuf.Duration flight_duration = 2;
}
```

Timestamp 和 Duration 底层结构相似，但语义不同；工具也可以据此分别映射为 `datetime` 和 `timedelta` 等类型。

### 相对时间片段

表示流中的时间片段时**应**使用 `google.protobuf.Duration`，字段名**应**以 `_offset` 结尾，并且注释**必须**说明偏移量相对于哪个时间点。

```proto
message AudioSegment {
  google.protobuf.Duration start_offset = 1;
  google.protobuf.Duration segment_duration = 2;
}
```

### 公历日期与时间

表示日历日期应使用 [`google.type.Date`][date]，表示墙上时钟时间应使用 [`google.type.TimeOfDay`][time of day]。日期字段**应**以 `_date` 结尾，民用时间或日期时间字段**应**以 `_time` 结尾。Date 和 TimeOfDay 不含时区；需要时区感知时应使用 [`google.type.DateTime`][datetime]。

### 民用时间戳

表示日期、时间以及可选时区的民用时间戳时**应**使用 [`google.type.DateTime`][datetime]，字段名**应**以 `_time` 结尾。

### 兼容性

因遗留约束或外部规范必须使用整数或 ISO-8601 字符串时，可以使用其他类型。整数应同时以含义（`time`、`duration`、`delay`、`latency`）和单位（`seconds`、`millis`、`micros`、`nanos`）作后缀，例如 `send_time_millis`；字符串包含含义即可，不加单位后缀。无论使用何种形式，都必须明确记录格式及原因。
