# 标准方法：Get

在 REST API 中，通常向资源 URI（例如 `/v1/publishers/{publisher}/books/{book}`）发送 `GET` 请求来获取资源。

面向资源的设计（[AIP-121][]）通过 `Get` 方法遵循这一模式：RPC 接收表示资源的 URI，并返回该资源。

## 指导

API **必须**为资源提供 Get 方法。Get 方法用于返回单个资源的数据。

Get 方法采用以下形式：

```proto
rpc GetBook(GetBookRequest) returns (Book) {
  option (google.api.http) = {
    get: "/v1/{name=publishers/*/books/*}"
  };
  option (google.api.method_signature) = "name";
}
```

- RPC 名称**必须**以 `Get` 开头，其余部分**应**使用资源消息名称的单数形式。
- 请求消息**必须**与 RPC 名称匹配，并以 `Request` 结尾。
- 响应消息**必须**就是资源本身（不存在 `GetBookResponse`）。响应通常**应**包含完整资源；如需返回部分响应，请参阅 [AIP-157][]。
- HTTP 动词**必须**为 `GET`。
- URI **应**包含一个与资源名称对应的变量字段，字段名**应**为 `name`，且该字段**应**是 URI 路径中的唯一变量；其余参数**应**映射为查询参数。
- `google.api.http` 注解中**不得**出现 `body` 键。
- **应**恰好有一个 `google.api.method_signature` 注解，值为 `"name"`。

### 请求消息

Get 方法使用统一的请求消息模式：

```proto
message GetBookRequest {
  // 要获取的图书名称。
  // 格式：publishers/{publisher}/books/{book}
  string name = 1 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      type: "library.googleapis.com/Book"
    }];
}
```

- **必须**包含资源名称字段，字段名**应**为 `name`；该字段**应**标注为必填，并**必须**标识所引用的[资源类型][aip-123]。
- `name` 字段的注释**应**说明资源名称模式。
- 请求消息**不得**包含其他必填字段；除其他 AIP 另有说明外，也**不应**包含其他可选字段。

**注意：** 请求对象中的 `name` 字段对应 RPC 的 `google.api.http` 注解中的 `name` 变量。使用 REST/JSON 接口时，该字段会根据 URL 的值自动填充。
