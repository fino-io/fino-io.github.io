# 范围

服务经常需要表示离散或连续值的范围，包括整数、浮点数和时间戳。范围的语义可能因类型而有细微差别。

## 指导

表示范围的资源或消息通常**应**使用同一类型的两个字段，并以 `start_`、`end_` 为前缀：

```proto
message Chapter {
  string title = 1;
  int32 start_page = 2;
  int32 end_page = 3;
}
```

### 包含或排除

大多数场景**应**使用包含起点、排除终点的半开区间 `[start_xxx, end_xxx)`。排除终点符合连续值的直觉，与 C++、Java、Python、Go 等语言一致，也便于拼接 `[0, x)`、`[x, y)`、`[y, z)`。

### 时间戳区间

符合 `google.type.Interval` 语义的两个时间戳范围**应**使用该通用消息，而不是自行定义起止字段，以便客户端逻辑在多个 API 中复用。若消息本身包含大量描述区间的附加信息，也可以使用单独的起止字段以避免额外嵌套。

### 例外

日期、“周一至周五”等概念通常使用包含终点的闭区间。此时**应**使用 `first_` 和 `last_` 前缀：

```proto
message Chapter {
  string title = 1;
  int32 first_page = 2;
  int32 last_page = 3;
}
```

只有确有强烈惯例时才使用闭区间，并且必须清楚记录范围是包含还是排除。
