# 标准方法：Delete

在 REST API 中，通常向资源 URI（例如 `/v1/publishers/{publisher}/books/{book}`）发送 `DELETE` 请求来删除资源。

面向资源的设计（[AIP-121][]）通过 `Delete` 方法遵循这一模式。RPC 接收资源 URI，通常返回空响应。

## 指导

除非用户使用没有价值，API **通常应**为资源提供 Delete 方法。

```proto
rpc DeleteBook(DeleteBookRequest) returns (google.protobuf.Empty) {
  option (google.api.http) = {
    delete: "/v1/{name=publishers/*/books/*}"
  };
  option (google.api.method_signature) = "name";
}
```

- RPC 名称**必须**以 `Delete` 开头；请求消息以 `Request` 结尾。
- 响应消息**应**为 `google.protobuf.Empty`；软删除时应返回资源本身；长时运行时必须返回解析为正确响应的 `google.longrunning.Operation`。
- HTTP 动词**必须**为 `DELETE`；资源名称字段**应**映射到 URI 路径，字段名**应**为 `name`，且为路径中的唯一变量。
- 不得有 `body`；方法签名通常应为 `"name"`，使用 ETag 或 force 字段时可以加入这些字段。
- 管理平面上的删除应具备[强一致性][strong consistency]。
- 存在子资源时**必须**返回 `FAILED_PRECONDITION`；若子资源全部是[单例资源][aip-156]，则必须允许删除，因为单例资源的生命周期与父资源绑定。

只有资源存在且成功删除时，Delete 才**应**成功；资源不存在时**应**返回 `NOT_FOUND`。

### 请求消息

```proto
message DeleteBookRequest {
  string name = 1 [
    (google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {
      type: "library.googleapis.com/Book"
    }];
}
```

请求**必须**包含名为 `name` 的资源名称字段，标注为必填、标识资源类型，并在注释中说明资源模式；不得包含其他必填字段，也不应包含未由 AIP 说明的可选字段。

### 软删除

有关软删除和恢复的完整指导已移至 [AIP-164](./0164.md)。

### 长时运行的删除

删除耗时较长时应使用长时运行操作；`response_type` 必须是非长时运行版本的返回类型（通常为 `google.protobuf.Empty`），并且必须同时指定 `metadata_type`。

### 级联删除

若允许删除资源及其全部子资源，API **应**提供 `bool force`，由调用方显式选择级联删除。`force` 未设置或为 `false` 且存在子资源时，服务**必须**返回 `FAILED_PRECONDITION`。

### 受保护的删除

提供 `etag` 的资源可以让 Delete 请求携带必填或可选 ETag。若提供的值与服务端计算值不匹配，请求**必须**返回 `ABORTED`。声明式友好的资源（AIP-128）**必须**为 Delete 提供 ETag。

### 资源存在时删除

使用客户端分配资源名称时，可以提供 `bool allow_missing`。资源不存在时该字段使请求成为无操作并成功；资源存在时照常删除。资源不存在时忽略 ETag。声明式友好的资源**应**暴露此字段。

### 错误

无论资源是否存在，权限检查都必须先于存在性检查；无权访问时必须返回 `PERMISSION_DENIED`（HTTP 403）。拥有权限但资源不存在时，除非 `allow_missing` 为 `true`，必须返回 `NOT_FOUND`（HTTP 404）。
