# AIP 每月同步计划

每月执行一次，用于将上游 AIP 的变更同步到本站。上游内容以 `upstream/google-aip` 为唯一来源；中文译文仅在对应英文原文发生变化时更新。

## 执行范围

- 同步 `upstream/google-aip` 的最新提交。
- 检查 `upstream/google-aip/aip/general/` 与当前版本的差异。
- 仅处理新增、删除或修改的 AIP；无差异时不改动站点文件。
- 英文页面由构建脚本从上游生成到 `docs/generated/`，不直接编辑。
- 对已翻译的 AIP，同步更新对应的 `docs/aip/general/*_zh.md`；新增 AIP 先保留英文入口，待提供中文翻译后再登记。

## 每月流程

1. 更新 `upstream/google-aip`，记录本次同步的上游提交范围。
2. 对比 `aip/general/` 的 Markdown 文件，列出新增、删除、修改和仅元数据变更。
3. 逐篇审阅有变化的英文原文：更新中文译文、标题、摘要和必要的内部链接；不因纯格式变化重译正文。
4. 新增或调整译文后，同步维护 `docs/aip/general/zh.yaml` 中的翻译状态与中文展示信息。
5. 运行 `npm run docs:build`，确认英文生成页、中文页、侧栏和语言切换链接均可构建。
6. 输出同步记录：上游提交、变更 AIP 列表、已完成翻译、待翻译项及任何需要人工确认的术语。

## 约束

- 不覆盖或直接编辑 `docs/generated/`；它是构建产物。
- 不修改 `upstream/` 之外的官方英文内容。
- 中文内容发生语义分歧时，以英文原文为准，并在同步记录中标注待确认处。
