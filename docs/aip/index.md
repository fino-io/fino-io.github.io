## 浏览方式

- [General：通用 AIP](/aip/general)：覆盖跨产品适用的 API 设计原则，按主题分类。
- [AIPs by Scope：按 Scope 浏览](/aip/scopes)：查看针对特定产品、平台或团队范围的 AIP。
- [中文翻译与页面布局计划](/aip/translation-plan)：了解后续翻译优先级和页面组织方式。
