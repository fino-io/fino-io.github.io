# AIPs by Scope：按范围浏览

除 General AIPs 外，AIP 还为特定产品、平台或团队保留独立的编号范围。Scope 不是新的规范层级，而是用于表达“这份指导适用于谁、可能在哪些地方扩展通用指导”。

## Scope 目录

| Scope | 中文名称 | 说明 | 官方目录 |
| --- | --- | --- | --- |
| General | 通用 | 面向跨产品、跨团队的通用 API 设计指导 | [浏览 General](https://google.aip.dev/general) |
| Cloud | Google Cloud Platform | Google Cloud Platform 相关 API 与 Cloud SDK 指导 | [浏览 Cloud](https://google.aip.dev/cloud) |
| Client libraries | 客户端库 | 客户端库生成、行为与兼容性指导 | [浏览 Client libraries](https://google.aip.dev/client-libraries) |
| Auth | 身份认证 | 认证、凭据与授权相关指导 | [浏览 Auth](https://google.aip.dev/auth) |
| Firebase | Firebase | Firebase 产品相关指导（当前官方目录标记为隐藏） | [浏览 Firebase](https://google.aip.dev/firebase) |
| Workspace | Workspace | Google Workspace 相关 API 指导 | [浏览 Workspace](https://google.aip.dev/apps) |
| Actions on Google | Actions on Google | Actions on Google 相关指导 | [浏览 Actions on Google](https://google.aip.dev/aog) |

## 如何阅读

建议先从 [General：通用 AIP](/aip/general/) 了解通用原则，再按 API 所属产品或团队查看对应 Scope。若 Scope 与 General 对同一主题给出不同指导，应结合目标 API 的适用范围与原文状态一并判断。

当前中文版先接入 Scope 目录与官方入口；具体 Scope 下的条目会沿用 `AIP 编号 + 中文标题 + 状态 + 原文` 的方式逐步补齐。
