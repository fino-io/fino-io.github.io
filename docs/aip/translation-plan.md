# 中文翻译与页面布局计划

本计划用于持续完善 AIP 中文站。中文译文仅作学习参考；出现歧义时以英文原文为准。

## 翻译范围与优先级

先完成 General AIP，再按实际需求扩展到各 Scope。General 的建议顺序如下：

1. **资源与方法**：AIP-121 至 AIP-136，建立资源设计与标准方法的主线。
2. **字段与交互**：AIP-140 至 AIP-165，覆盖字段、分页、过滤、更新与软删除。
3. **兼容性与工程实践**：AIP-180 至 AIP-194，覆盖版本、兼容性、文档和错误处理。
4. **特定 Scope**：仅在有明确使用场景后翻译 Cloud、Auth、Client Libraries 等分类。

每个阶段优先选择被其他 AIP 高频引用、对 API 设计影响大的条目；状态为 Draft 或 Reviewing 的条目在正文前明确标注其稳定性。

## 单篇翻译流程

1. 确认 `upstream/google-aip` 中的英文原文和状态。
2. 在 `docs/aip/general/` 新建 `NNNN_zh.md`，保留原文链接与 CC BY 4.0 / Apache 2.0 许可说明。
3. 更新 `docs/aip/general/zh.yaml` 中对应条目的中文标题、摘要和 `translated` 状态。
4. 在 `docs/aip/general/index.md` 将该条目连接到中文页；仅将高优先级条目加入侧栏。
5. 执行 `npm run docs:build`，检查中英文互跳、站内链接、标题层级和移动端可读性。

`docs/generated/` 是英文构建产物，不编辑也不提交；英文内容只从 `upstream/` 更新。

## 页面布局

### 总览页

`/aip/` 只承担三个入口：General、按 Scope 浏览、翻译计划。展示已翻译范围和原则，不重复完整目录。

### General 目录页

`/aip/general/` 按官方分类展示全部条目。每个条目显示中文标题、官方状态和英文入口；已有译文时，中文标题链接到站内中文页。

### 译文详情页

每篇 `NNNN_zh.md` 保持一致结构：中文标题、原文与许可说明、正文、相关 AIP、变更记录。英文页与中文页通过语言切换器双向跳转。

### 侧栏

侧栏只保留总览、分类目录和已翻译的重点条目；完整列表留在 General 目录页，避免长侧栏挤占阅读空间。

## 完成标准

一篇译文完成的最低标准是：术语统一、所有内部 AIP 引用可访问、英文原文可直达、构建通过。上游原文发生实质更新时，应重新核对对应中文译文。
