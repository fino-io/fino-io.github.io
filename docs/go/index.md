这份指南按“写出小程序 → 建立工程习惯 → 掌握并发与服务 → 完成可交付项目”的顺序展开。面向零基础读者与其他语言的开发者，每章包含概念、示例、常见问题和验收标准。以 [Go 官方文档](https://go.dev/doc/)为依据，参考 [roadmap.sh Go 路线](https://roadmap.sh/golang)的主题覆盖与 [Learn Go with Tests](https://quii.gitbook.io/learn-go-with-tests)的练习方式，重新组织成中文学习材料；不是这些资料的逐篇翻译。

**示例基线为 Go 1.22+**，使用标准库的现代 HTTP 路由；安装时选择官方当前受支持的稳定版本。基础章节与两个实战项目均无第三方 Go 依赖，应用扩展再按需要复用成熟库。基线表示语法要求，不代表建议在生产中使用已停止维护的版本。资料核对日期：2026-10-08。

## 如何使用示例

采用“读概念 → 运行示例 → 改变输入 → 写测试 → 解释结果”的循环。带 `package main` 的完整代码块可独立保存为 `main.go`，在初始化过模块的目录运行 `go run .`；同一目录一次保留一个入口。标为“片段”的代码用于展示接口或操作，需要放进相应函数并补齐 import。项目章节明确列出文件名，可直接照目录保存运行。

每章练习先独立实现，再用验收标准检查。先保证顺序程序正确，再增加并发；先明确输入、输出和失败条件，再选择框架。标准库足以完成入门项目，后续需要复杂 CLI、数据库访问或并发编排时，使用 Cobra、pgx、errgroup 等已有方案。

## 选一条学习路径

- **第一次学习编程**：从 01 开始，配合 [A Tour of Go](https://go.dev/tour/)逐个运行实验，优先完成 19，不急于微服务。
- **从 Python、Java、JavaScript 转入**：重点读 03–06 和 11–12，理解值复制、接口、错误返回与取消，避免直接搬用原语言的对象模型。
- **目标是后端服务**：完成 20 后接入 PostgreSQL，再学习认证、迁移、日志与部署；API 契约可结合站内 [Google AIPs](/aip/general/)和 [gRPC 指南](/grpc/guides/)。

从 [01 · 环境与工具链](./toolchain)开始；已有基础可以直接挑战 [日志统计 CLI](./project-cli)。
