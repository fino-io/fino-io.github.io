这份指南面向中文自学者，按“先写小程序，再组织项目，最后进入应用开发”的顺序展开。以 [Python 官方教程](https://docs.python.org/zh-cn/3/tutorial/) 校对语言概念，参考 [Harvard CS50P](https://cs50.harvard.edu/python/) 的入门教学顺序与 [roadmap.sh Python 路线](https://roadmap.sh/python) 的主题覆盖，结合工程实践重新编写讲解、示例和项目。本文是原创学习整理，不是上述课程的逐篇翻译。

示例以 **Python 3.12 及以上**为基线；每章注明需要的第三方依赖。基础阶段以标准库为主，应用阶段复用 pytest、HTTPX、FastAPI、Pydantic 和 pandas 等成熟方案。资料核对日期：2026-10-08。

## 学习安排

完全初学者先跟随“起步与语言基础”学习基本程序结构，再进入官方教程；已有编程经验的读者可通过每章练习检查掌握程度。每周 5–8 小时、10–12 周是建议节奏，遇到困难可以放慢，完成标准比天数更重要。

- **第 1–3 周 · 语言基础**：完成“起步与语言基础”，能处理用户输入、容器和文件，并解释失败原因。
- **第 4–6 周 · 工程实践**：完成“工程实践与语言进阶”，能组织模块、标注接口、测试边界，交付项目一。
- **第 7–9 周 · 应用开发**：完成“应用开发与生态”，掌握 HTTP、SQL 和并发边界，交付项目二。
- **第 10–12 周 · 项目完善**：完成项目三，结合[项目交付](./projects)与[方向资料](./resources)，为三个项目补 README、异常场景和可复现运行流程，并选择下一阶段方向。

采用“读概念 → 运行示例 → 修改输入 → 完成练习 → 解释结果”的循环。代码块标注文件名时保存到对应文件；其余示例可保存为单独脚本。终端命令在项目虚拟环境中运行，不要把终端提示符复制进代码。

## 如何选择参考资料

主教材选一份，其他作为查阅资料：零基础可用 [CS50P](https://cs50.harvard.edu/python/) 配合本指南练习，有编程基础可从 [官方中文教程](https://docs.python.org/zh-cn/3/tutorial/) 开始；[Python 标准库](https://docs.python.org/zh-cn/3/library/) 用于查询真实 API，[Python Packaging User Guide](https://packaging.python.org/) 用于工程与打包。roadmap.sh 用来检查主题覆盖，不要求一次学完所有分支。

Web 方向继续学习 Django 或 FastAPI 的正式文档、SQL 和部署；数据方向继续学习 NumPy、统计与 SQL；自动化方向补充任务调度、幂等和日志。元类、描述符、C 扩展等可在出现真实需要时再读语言参考，初期先掌握函数、数据、错误和测试。

遇到问题先确认解释器，再缩小失败输入并读 traceback；遇到第三方库优先阅读对应版本的官方文档。完成一个包含安装说明、样本、测试和已知限制的项目后，再扩展下一阶段。

从 [环境、解释器与虚拟环境](./toolchain) 开始；有经验的读者可以先完成 [项目一](./project-cli)，再按遇到的问题回到对应章节。
